01 / 四个面板

一个工作台， 四种看法。

写代码的、拖积木的、跟模型说话的、看诊断的 —— 四件事各占一格。 它们看着是四个工具，接的是同一棵 AST和同一个真实编译器。

文本视图

CodeMirror 6，正常写代码。语法高亮、括号匹配、自动闭合、缩进、补全（关键字、类型、{{stdlib_modules}} 个标准库模块），悬停提示能给出规范章节号。文件开在标签页里，开第二个不会把第一个顶掉；小黑点按内容算，撤销回上次保存的版本就自动消失。

  • ·CodeMirror 6
  • ·悬停给规范章节号
  • ·{{stdlib_modules}} 个模块的补全

块视图

Blockly 13，拖块写程序。工具箱第一屏是「入门」：函数、打印、调用、数字/字符串、变量、返回；另有现成的 C 函数声明块（printf / puts / malloc / free / exit，参数表自动填好）—— 每个 JHYY 程序的第一行不用再靠「原始代码」逃生舱手打。

  • ·Blockly 13
  • ·独占整块编辑区
  • ·C 声明块现成

Claude Code

右侧栏里的内嵌对话面板，驱动你机器上已经装好的 claude CLI（走 stdin 的流式模式，多轮上下文是连着的）。Claude 挂上了 jhyy MCP server，能调 jhyy_check 拿真实编译器的诊断，而不是靠猜。侧栏还有个「只读」开关，打开后系统提示里会写明「用户要求你不要修改任何文件」。

  • ·驱动本机 claude CLI
  • ·jhyy MCP server
  • ·只读开关

底部面板

默认收起的一块，点「检查」弹到问题页，点「运行」弹到终端页。终端是真 shell（默认 MSYS2 的 bash，PowerShell 和 cmd 也能切），优先走真 PTY；node-pty 装不上时退到管道，这时 vim、top 这类全屏 TUI 跑不了 —— 而且退的时候状态栏会显示徽标，不静默变假。

  • ·问题 + 终端
  • ·真 PTY 优先
  • ·降级时显示徽标
02 / 一棵 AST，两个投影

最有说服力的一条： 积木和文本共享同一棵树。

不是两套代码生成器互相同步，是同一棵树的两个投影。

01 改块 → 文本

改块，文本实时跟着变。

IDE 重新生成整份源码并替换文本视图，光标按最长公共前缀 / 后缀映射回原位 —— 你不会看到光标莫名其妙跳到别处。

改块 → 文本同步
02 改文本 → 积木

改文本，切回时重建。

每敲一个键就重建块，画布会抖到没法用 —— 所以 IDE 不在打字时重建，等你切回块视图才重建。两条路的往返因此是无损的。

03 独占

积木和文本从不同时占屏。

块画布满整个编辑区，代码编辑器整个消失 —— 用标题栏的积木按钮、Ctrl+Shift+B 或命令面板切过去。切换时两边都保留状态：画布的缩放和平移留着，编辑器的撤销历史和光标位置也留着。

04 不透明块

表达不了的语法不会静默消失。

泛型、turbofish、闭包、指针、借用、切片、defer、asm!、属性 —— 这些落进一个不透明块，里面装着原始源码文本。挪它、删它都行；只要你不动它，那部分代码逐字节往返无损。

03 / 现状与边界

什么能用， 什么不能用。

这一屏把两边都写出来 —— 只讲做到了什么，等于不讲。

✓ 已经成立

裁判永远是真实编译器

IDE 从不猜程序对不对，它去跑 jhyy.exe，解析它的 file:line:col: error: … 输出，把编译器自己的诊断显示给你。菜单栏、命令面板、快捷键是同一张命令表的三种看法，所以菜单里标出来的快捷键一定就是真能按的那个。

✗ 还没有

边界写在明面上

只构建和验证了 Windows x64，Linux / macOS 未构建。IDE 不含编译器 —— 每次编译、每条诊断都由你自己装的 jhyy.exe 出（查找顺序：设置里配的路径 → 环境变量 JHY_EXE → 仓库旁的开发构建 → 官方安装版 → PATH）。安装包没有代码签名，SmartScreen 会拦一下。

→ 正在推

源码树领先于已发布版本

CHANGELOG.md 顶部还有一节「未发布」（终端大改、设置对话框等）—— 源码树已经领先于任何一个已发布版本。

◆ 一条重要的区分

「共享 AST」证明的是什么

两个视图共享一棵 AST，证明的是同一份真相——它们是同一棵树的两个投影。它不证明「积木能表达全部语法」：表达不了的部分以不透明块保留原始源码，那部分仍然只有文本视图能改。

04 / 看数字

IDE 自己说的话， 不算数。

IDE 的解析器和打印器必须跟真实编译器说同样的话。这靠编译器仓库自己的示例程序来保证 —— 语料是编译器仓的 compiler/tests/examples/，会随编译器一起长。
