一门语言， 四个项目， 一个闭环。

— JHYY（机会翼游）是一门自举的、静态类型、面向表达式的系统编程语言。编译器用自己写的，后端是自研的 amd64 发射器（没有 LLVM，也没有 vendor 进来的 QBE）。这个家族有四个项目：编译器、IDE、操作系统，以及把语言带到 VEX V5 Brain 上的嵌入式目标。

01 / 四个项目

编译器是地基， 其余三个站在上面。

它们共享同一门语言和同一套工具链。下面每个卡片写的是项目现在真的做到哪一步——不含计划中的部分。

01 稳定 · v4.1.4

JHYY 编译器

编译器唯一的实现是 compiler/src0/*.jhyy——树里没有 bootstrap 的 C 编译器，也没有 vendored 的后端。它编译自己，再让编译出来的自己编译自己，而门要求这两代产出的汇编逐字节相同。不动点是跑出来的，不是假设的。

后端是自研的内存内 amd64 代码发射器，产出 Windows 的 PE/COFF 与 Linux 的 SysV 汇编。标准库八个模块，arena 是一等公民。

JHYY IDE

桌面工作台。Blockly 积木和 CodeMirror 文本共享同一棵 AST——改一边，另一边跟着重建。积木表达不了的语法以不透明积木保留原始源码，不会静默丢失。右侧是能直接对话本机 claude CLI 的面板。

03 孵化中 · 重整设计基线

JiHuiYiYou-OS

用这门语言写的 microkernel。方向是 Cap<T> capability、lang-debug ABI 和 GUI 三条线。仓库目前只有一份 UEFI x64 引导 spike——它已经实测出 EFI 调用约定、ConOut 的协议偏移和 isa-debug-exit 的退出码通路。设计文档正在重整。

OS 概览
04 孵化中 · Day 0 已完成

JiHuiYiYou-for-VEX

让 JHYY 直接跑在 VEX V5 Brain（Xilinx Zynq / Cortex-A9）上。路线是 JHYY 直出 ARM 机器码，不是转译成 C++——但换掉的只是 clang 的位置，ld 及以下原样不动，链官方 SDK 出 .bin。第 0 步已完成：VEX 侧的未知数全部变成实测值，写成了事实基线。

实测也踩出了三个必须记住的坑：MSYS2 自带的 objdump 是 x86-only，SDK 的 clang 是 8.0.0，而「指令集 = ARM 态 4 字节定长」这条结论依赖具体 clang 版本。

02 / 编译器

三种人， 三种入口。

同一个编译器，新手、OS 开发者、研究者要找的东西不一样。所以文档也分三层。

A OS 与裸机

写内核要什么

#[no_std]、#[naked]、#[link_section]、内联 asm!、volatile 与内存屏障、defer。四个 target，其中两个是 freestanding。UEFI 入口路径尚未完工——这一条写在明面上。

B 语言设计与自举

编译器怎么搭的

前端 → IL 文本 → 自研 amd64 发射器 → PE/COFF 或 ELF。自举闭环的门在本地跑：N=10 代的 .il 与 .s 逐字节相等。语言规范与 ABI 锁在 v4.0.0，是可引用的契约。

D Arena

内存怎么管

没有 GC，没有托管运行时。arena 既是分配器也是生命周期工具：arena_reset 复位复用，arena_free 整块释放。对齐保证、失败返回、销毁顺序都写进文档，不靠猜。
