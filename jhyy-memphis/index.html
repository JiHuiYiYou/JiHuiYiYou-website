JHYY (机会翼游) 是一个 自研、静态类型、表达式导向的系统编程语言。 编译器用自己编译自己,产出 byte-equal 的 QBE 中间表示, 最终生成原生 x86-64 PE 二进制。下一个里程碑:自研操作系统。

关于 / About

为什么是 JHYY?

大多数编程语言只是别人的工具。JHYY 是工具链的每一层——从 lexer 到 codegen, 从汇编到 ABI——都从零写起,然后让这门语言自己重新实现自己,直到 byte-equal 闭环。 这不是演示项目:它能编译、链接、跑通,也能跑自己。

🎯 设计目标

  • 自举编译器 — jhyy 编 jhyy, byte-equal `.il` 闭环
  • 原生性能 — QBE 后端,无 runtime / 无 GC,直产 PE/COFF
  • OS 友好 — 服务于 jhyy_OS 的语言扩展
  • 工程化 — 完整 spec / ABI 白皮书 / 回归套件

🧬 与众不同

  • 两套等价的编译器实现 — C-side 与 jhyy-side
  • Stage 2 N=4 byte-equal 闭环 — 5 个世代输出同 sha256
  • 多 ABI 多调用约定 — Windows x64 / System V / freestanding EFI
  • 11 个 MCP 工具 + VSCode 扩展 + 一键安装包
语言特性 / Features

一个 现代系统语言
该有的样子

静态类型 + 表达式导向 + 一等公民的函数。结构体、枚举、模式匹配、切片、命名空间、C FFI、模块系统——都有,但没有 GC,没有运行时垃圾。

T

静态类型

i8/i16/i32/i64,u*/f*/bool,指针 *T,定长数组 [T; N],切片 [*]T,struct / enum 全套。

{ }

表达式导向

if 是表达式、match 是表达式、块也是值。while / for i in start..end / break / continue 全员。

⇆

match + 穷尽

字面量 / 范围 / 枚举 / 通配符全支持,带穷尽性检查。0 | 1..10 => ... 区间 or-pattern 写法。

⇄

C FFI

extern fn printf(...) 直接调 C。多文件链接、结构体按值传参、命名空间 mod::fn() 一气呵成。

M

模块系统

import + 传递性导入,多文件 CLI 编译,mod::fn() 命名空间访问。运行时 Arena 分配器也可经 FFI 调。

∅

零 runtime

无 GC、无垃圾回收、无运行时反射。直接 QBE → as → ld → 原生 .exe。想跑哪跑哪。

架构 / Architecture

一条 流水线,两条 路径

代码 / A tour of the syntax

看一眼 就懂了

函数、变量、控制流、struct、match、enum、FFI——全部一气呵成。

hello.jhyy 
// 类型 / 函数 / 控制流 / struct / match / enum / FFI
type Point = struct { x: i32, y: i32 }

fn dist_sq(a: Point, b: Point) -> i32 {
    let dx = a.x - b.x;
    let dy = b.y - a.y;
    dx * dx + dy * dy
}

fn classify(n: i32) -> *u8 {
    match n {
        0        => "zero",
        1..10    => "single digit",
        10 | 20  => "round number",
        _        => "other",
    }
}

extern fn printf(fmt: *u8, val: i32) -> i32;

fn main_jhyy() -> i32 {
    let p = Point { x: 3, y: 4 };
    let q = Point { x: 0, y: 0 };
    printf("d² = %d\n", dist_sq(p, q));
    printf("%s\n", classify(42));
    0
}
